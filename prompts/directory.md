请识别图片中的目录内容，并生成标题层级规则。

## 任务

1. **提取目录**：识别图片中的完整目录内容
2. **生成标题规则**：根据目录结构，制定标题层级规则

## 输出格式

请按以下JSON格式输出（只输出JSON，不要其他内容）：

```json
{
  "directory": "完整的目录文本，保持层级缩进",
  "headingRules": "标题层级规则说明，例如：一级标题(#)用于章名如'第一章'、'第二章'；二级标题(##)用于节名如'1.1'、'1.2'；三级标题(###)用于小节如'1.1.1'；四级标题(####)用于更细分的内容"
}
```

## 示例

输入目录图片后输出：
```json
{
  "directory": "第一章 概述 ............................ 1\n  1.1 背景介绍 ........................ 1\n  1.2 研究目的 ........................ 2\n第二章 文献综述 ........................ 5\n  2.1 国内研究 ........................ 5\n  2.2 国外研究 ........................ 8",
  "headingRules": "一级标题(#)用于章名（第一章、第二章等）；二级标题(##)用于节名（1.1、1.2、2.1等）；三级标题(###)用于更细分的小节内容"
}
```

## 注意事项

1. 目录文本要保持原有层级，使用空格缩进表示层级
2. headingRules要具体说明什么情况下用什么级别的标题
3. 只输出JSON，不要输出其他任何内容
